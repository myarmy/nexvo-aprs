# Nexvo APRS — RepeaterBook API usage controls

Nexvo APRS is a non-commercial Android application for licensed amateur-radio operators. RepeaterBook data will only support an on-demand nearby-repeater list/map. The application will not mirror, republish, export, sell, or provide a proxy API for RepeaterBook data.

## Authentication and storage

- Every user supplies their own RepeaterBook API token.
- The token is encrypted with AES/GCM using a non-exportable key generated by the Android Keystore provider.
- There is no plaintext or device-ID-derived fallback. If Android Keystore is unavailable, the token is not stored and the feature remains disabled.
- Tokens are never uploaded to the Nexvo server, included in logs, analytics, crash reports, APK resources, or source control.

## Request and cache controls

- Limit: at most 1 RepeaterBook request per device/user per 60 seconds; no burst allowance.
- Duplicate requests with the same normalized country, coordinates, radius and filters are coalesced while one is in flight.
- A successful result is cached locally for 24 hours. An identical query during that period is served only from the device cache.
- Manual refresh cannot bypass either the 60-second request limit or an active HTTP 429 cooldown.
- Initial expected use: up to 10 lookups per active user per day, fewer than 10 test users, normally fewer than 100 total requests/day.
- Initial public-test ceiling: 100 users and 1,000 total requests/day. Distribution will be paused and RepeaterBook contacted before exceeding this ceiling.

## Geographic and result scope

- Initial release is restricted to Türkiye (`TR`) only.
- A query is centered on the user's current or explicitly selected position.
- Maximum search radius: 200 km.
- Maximum displayed/stored results per query: 250 repeaters.
- No country-wide bulk download, background crawling, sequential grid search, database synchronization, or unattended polling.

## HTTP 429 and failures

- `Retry-After` is honored when supplied.
- Without `Retry-After`, cooldowns use exponential backoff: 60, 120 and 240 seconds, with 0–20% random jitter.
- Automatic retries stop after 3 attempts. The feature then remains in cooldown and requires a later user action.
- 429 responses never fall through to an immediate duplicate request.
- Network/5xx failures use the same maximum of 3 attempts; 4xx authentication/authorization failures are not retried.

## Attribution and redistribution safeguards

- Every RepeaterBook-derived view displays `Data © RepeaterBook — repeaterbook.com` with a working link to RepeaterBook.
- The source and last-updated time are visible to the user.
- Cached records remain inside the app sandbox and are not exposed through the Nexvo server or any public endpoint.
- The app does not allow CSV/JSON export or redistribution of RepeaterBook results.
